# Search Users

## Questions this document answers

* How can I search for a user on Socioverse?
* How do I find someone by their username?
* Where is the search bar on Socioverse?
* How do I visit someone's profile using search?
* How can I look up a username?
* How do I find a profile using the search bar?
* How do I search for people on the platform?
* How can I open a user's profile from search results?

## Answer

To search for a user on Socioverse:

1. Go to the **search bar at the top** of the page.
2. Type the **username** of the user you want to find.
3. The search results will show matching usernames.
4. Click on the **username** from the results.

You will be taken directly to that user's **profile page**.

## Notes

* You must enter the **correct username** to find the user.
* Clicking on a username in the search results will open their profile.

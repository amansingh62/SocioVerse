## Answer

To create a post on Socioverse:

1. Click **Home** on the menu bar.
2. Open the **post modal**.
3. Write your content in the **textarea**.
4. If you want to upload media, select an **image file**.
5. Click the **Post** button to publish your post.

## Media Upload Rules

* Only **image files** are supported.
* Supported formats:

  * PNG
  * JPEG / JPG
  * WEBP
  * AVIF
* Maximum image size: **5 MB**.
* Files larger than 5 MB will be rejected.

## Notes

* You can post **text only** or **text with an image**.
* Only the supported image formats can be uploaded.
* Other file types are not allowed.
